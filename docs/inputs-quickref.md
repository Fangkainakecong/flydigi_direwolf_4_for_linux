# 已识别的按键与轴（速查）

> 依据：`docs/input-report.md`（逐字节实测）、`docs/findings-motion.md`（体感）
> 适用：冰原狼4 2.4G dongle `045e:028e`，固件 4.0.7.2
> 数据：`data/txt/` 下的文本存档

## 一句话

Dongle 上报的是**标准 Xbox 360 报文（20 字节）加长到 32 字节**：
`[2..13]` 与 XInput 完全一致（xpad 即插即用），飞智把自家键位位图放在
`[17..20]`、三轴角速度放在 `[14..16]`。

## 报文总览

| 偏移 | 内容 | 状态 |
|---|---|---|
| `[0..1]` | `00 14` 报告 ID / 长度 | ✅ |
| `[2..3]` | 标准按钮字（XInput 语义） | ✅ |
| `[4..5]` | LT / RT 模拟量 | ✅ |
| `[6..13]` | 四轴摇杆（`int16`） | ✅ |
| `[14..16]` | 三轴角速度（`int8`） | ✅ 见第 6 节 |
| `[17..20]` | 飞智键位位图（32 位） | ✅ 含 M1/M2/FN/Turbo/Home |
| `[21..24]` | 状态字节 | ⚠ 不是姿态，含义未知 |
| `[25..31]` | 保留 | `[25]/[26]` 镜像扳机，其余 0 |

## 2. 扳机与摇杆

| 偏移 | 含义 | 范围 / 方向 |
|---|---|---|
| `[4]` | LT 模拟量 | 0（松开）→ 255（到底） |
| `[5]` | RT 模拟量 | 同上 |
| `[6..7]` | 左摇杆 X | 右正左负，实测 −32768..+32767 |
| `[8..9]` | 左摇杆 Y | **上正下负** |
| `[10..11]` | 右摇杆 X | 右正左负 |
| `[12..13]` | 右摇杆 Y | 上正下负 |

四个方向都能顶到满量程；与 XInput 语义一致。

## 3. 飞智键位位图 `[17..20]`

32 位小端，键 `k` 在 `[17 + k//8]` 的第 `k%8` 位：

| 字节 | 位0 | 位1 | 位2 | 位3 | 位4 | 位5 | 位6 | 位7 |
|---|---|---|---|---|---|---|---|---|
| `[17]` | 十字上 | 十字右 | 十字下 | 十字左 | A | B | Back | X |
| `[18]` | Y | Start | LB | RB | LT | RT | L3 | R3 |
| `[19]` | C（无） | Z（无） | **M1** | **M2** | M3（无） | M4（无） | M5（无） | M6（无） |
| `[20]` | **FN** | **Turbo** | — | **Home** | — | — | — | — |

```
M1    = [19] & 0x04
M2    = [19] & 0x08
FN    = [20] & 0x01
Turbo = [20] & 0x02
Home  = [20] & 0x08
```

* 按住时**持续置位**，松开即清，不是脉冲。
* 位图里带一份标准键副本，这是**板载重映射的落点**（固件改的是位图，
  不是上面的标准按钮字）。
* M3–M6、C、Z 是协议预留槽，冰原狼4 没有这些实体键，实测从未置位。

## 4. 21 个实体键全表

| 键 | 标准按钮字 | 位图 | xpad 可见 |
|---|---|---|---|
| A / B / X / Y | `[3]` 0x10/0x20/0x40/0x80 | `[17]` 0x10/0x20/0x80、`[18]` 0x01 | ✅ |
| LB / RB | `[3]` 0x01 / 0x02 | `[18]` 0x04 / 0x08 | ✅ |
| LT / RT | 模拟量 `[4]`/`[5]` | `[18]` 0x10 / 0x20 | ✅ |
| L3 / R3 | `[2]` 0x40 / 0x80 | `[18]` 0x40 / 0x80 | ✅ |
| Start / Back | `[2]` 0x10 / 0x20 | `[18]` 0x02、`[17]` 0x40 | ✅ |
| 十字 上/下/左/右 | `[2]` 0x01/0x02/0x04/0x08 | `[17]` 0x01/0x04/0x08/0x02 | ✅ |
| Home | `[3]` 0x04 | `[20]` 0x08 | ✅ |
| **M1 / M2** | **无** | `[19]` 0x04 / 0x08 | ❌ |

M1/M2/FN/Turbo 在标准按钮字里完全没痕迹，原厂 xpad 下是死键——
这是要自建 daemon 的直接原因。

## 5. 体感：三轴角速度 `[14..16]`

| 偏移 | 轴 | 类型 | 说明 |
|---|---|---|---|
| `[14]` | 偏航 yaw（绕竖轴） | `int8` | 左右转头，rms 26.0 |
| `[15]` | 俯仰 pitch（绕横轴） | `int8` | 前后点头，rms 44.4 |
| `[16]` | 横滚 roll（绕前后轴） | `int8`（疑似 4 位） | 幅度小，只见到 `00/0F/F0/FF` |

* 平放静止时三字节**全 0**（99.3% 的帧），零偏基本为零。
* 更新率约 **89 Hz**，1000 Hz 报文里其余帧是重复值。
* **不需要发 cmd17**：厂商流开关不影响它。
* 量纲未标定，做体感鼠标前要补一次"匀速转 360°"的采集。

## 6. 加速度计：硬件是六轴，但 2.4G XInput 报文不输出（2026-11-19）

做法：7 个静态姿态各录 2 秒 + 一段保持水平上下颠（`scripts/flydigi_accel_probe.py`）。
数据：`captures/accel_20261119-011738.bin`（及 011453 复测，结论一致）。

| 姿态 | `[14]` | `[15]` | `[16]` | `[21]` | `[22]` | `[23]` | `[24]` |
|---|---|---|---|---|---|---|---|
| 平放正面朝上 | 0 | 0 | 0 | 128.1 | 130.1 | 129.1 | 126.9 |
| 翻转正面朝下 | 0 | 0 | 0 | 128.0 | 130.5 | 129.5 | **133.0** |
| 左侧朝下 | 0 | 0 | 0¹ | 128.5 | 130.0 | 128.9 | 127.0 |
| 右侧朝下 | 0 | 0 | 0¹ | 128.3 | 130.0 | 129.0 | 127.0 |
| 充电口朝下 | 0 | 0 | 0 | 128.8 | 130.0 | 129.0 | 127.0 |
| 握把朝下 | 0 | 0 | 0 | 128.5 | 130.0 | 129.0 | 127.0 |
| 回到正面朝上 | 0 | 0 | 0 | 128.4 | 130.0 | 129.0 | 127.0 |
| 水平上下颠 | sd 36 | sd 67 | sd 14 | sd 0.45 | 0.07 | 0.08 | 0.19 |

¹ `[16]` 静止时有偶发 ±16 跳变（sd≈6.7），是该轴自己的粗量化抖动，均值仍为 0。

结论：

1. **三轴角速度 `[14..16]` 在七种姿态下均值都是 0** —— 陀螺仪不受重力影响，
   符合预期。
2. **只有 `[24]` 随姿态变化**：正面朝下 127→133（+6），翻面过程中平滑经过
   128/130/131/132，确实跟踪重力方向。
3. 但 `[24]` 在"上下颠"（沿重力方向剧烈线性加速）时 sd 只有 0.19 ——
   真正的加速度计会在这一阶段出尖峰。所以它**不是加速度计原始输出**，
   更像固件算出来的低分辨率"朝向/状态"字节（约 3 counts/g，不响应瞬态）。
4. 其余字节（`[21][22][23]`、`[25..31]`）不随姿态或加速度变化。

**最终结论：标准 32 字节报文里没有可用的加速度计数据，体感只有三轴角速度。**

但**硬件确实是六轴**（官方说明书与 Amazon 页面都写 `6-Axis Gyro`；飞智帮助中心
还写明"手柄静止约 2.5s 无数据变化时，自动校准陀螺仪和加速度"）。所以加速度计
存在，只是在 2.4G 的 XInput 报文里不输出——同代的 Vader 3 Pro 在 **DInput 模式**
的 HID 报文里能读到 int16 三轴加速度（4096 = 1g），冰原狼4 很可能也一样。
外部资料调研与验证顺序见 [findings-public-sources.md](findings-public-sources.md)。

```bash
# 切到 DInput（2.4G 档，长按 FN+A，指示灯变蓝）后，被动看一眼有没有 0x04/0xEF 报文
sudo python3 scripts/flydigi_dinput_probe.py
```

### 验证脚本

```bash
sudo python3 scripts/flydigi_accel_probe.py
```

7 个静态姿态（正面朝上 / 朝下 / 四边朝下 / 再回正面）+ 一段"保持水平上下颠"，
每个姿态按一次回车自动录 2 秒。跨姿态极差 ≥8 的字节会被标成加速度计候选。
结果落到 `captures/accel_<时间>.bin/.json`。
