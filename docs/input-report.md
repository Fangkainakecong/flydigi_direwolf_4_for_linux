# 冰原狼4 (Direwolf 4) 2.4G 输入报文布局

> 测量依据：`captures/inputs_20261119-000752.bin`（124 914 帧，171 s，
> Windows 全默认键位，未开厂商流）
> 测量脚本：`scripts/flydigi_button_probe.py` + `scripts/flydigi_capture_decode.py`
> 日期：2026-11-19

## 结论一句话

Dongle 上报的是一个**标准 Xbox 360 报文（20 字节）加长到 32 字节**：
`[0]` 报告 ID、`[1]` 长度 0x14、`[2..13]` 与 XInput 完全一致（所以 xpad
不装任何驱动也能当普通手柄用），飞智把自家按键位图放在 `[17..20]`、
运动数据放在 `[14..16]`/`[21..24]`。

## 逐字节

| 偏移 | 含义 | 说明 |
|------|------|------|
| `[0]` | `0x00` | 报告 ID |
| `[1]` | `0x14` | 与 Xbox 360 报文一致（20 字节） |
| `[2..3]` | 标准按钮字，小端 | 见下表，**与 XInput 位定义完全相同** |
| `[4]` | LT 模拟量 0..255 | 松开 0，到底 255 |
| `[5]` | RT 模拟量 0..255 | 同上 |
| `[6..7]` | 左摇杆 X，`int16` 小端 | 右正左负，满量程 ±32768 |
| `[8..9]` | 左摇杆 Y，`int16` 小端 | **上正下负**（与 XInput 相同） |
| `[10..11]` | 右摇杆 X，`int16` 小端 | 右正左负 |
| `[12..13]` | 右摇杆 Y，`int16` 小端 | 上正下负 |
| `[14..16]` | 运动数据（未解码） | 静止时也在大幅跳动，不是时间戳 |
| `[17..20]` | **飞智键位位图**，32 位小端 | 见下表，含 M1/M2/FN/Turbo/Home |
| `[21..24]` | 运动/姿态数据（未解码） | 静止时 ≈ `80 82 81 7e`，有噪声 |
| `[25..31]` | 0 | 保留 |

> `[25]`、`[26]` 在按住 LT/RT 时会镜像 `[4]`/`[5]` 的值，本文档按原样记录，
> 实现时用 `[4]`/`[5]` 即可（XInput 语义）。

## 标准按钮字 `[2..3]`

低字节 `[2]`：

| 位 | 按钮 |
|----|------|
| 0x01 | 十字 上 |
| 0x02 | 十字 下 |
| 0x04 | 十字 左 |
| 0x08 | 十字 右 |
| 0x10 | Start |
| 0x20 | Back |
| 0x40 | L3（左摇杆按下） |
| 0x80 | R3（右摇杆按下） |

高字节 `[3]`：

| 位 | 按钮 |
|----|------|
| 0x01 | LB |
| 0x02 | RB |
| 0x04 | Home（LOGO） |
| 0x08 | 未用 |
| 0x10 | A |
| 0x20 | B |
| 0x40 | X |
| 0x80 | Y |

这就是 Xbox 360 的位定义，因此 **xpad 驱动读到的就是正确的手柄输入**，
A/B/X/Y/肩键/扳机/摇杆/十字/Start/Back 全部即插即用。

## 飞智键位位图 `[17..20]`

32 个槽位，编号沿用上游 openflydigi 的 `KEY_NAMES`（`reference/openflydigi/mapping.py`）。
键 `k` 位于 `[17 + k // 8]` 的第 `k % 8` 位。

| 字节 | 位 0 | 位 1 | 位 2 | 位 3 | 位 4 | 位 5 | 位 6 | 位 7 |
|------|------|------|------|------|------|------|------|------|
| `[17]` | 十字上 | 十字右 | 十字下 | 十字左 | A | B | Back | X |
| `[18]` | Y | Start | LB | RB | LT | RT | L3 | R3 |
| `[19]` | C(无) | Z(无) | **M1** | **M2** | M3(无) | M4(无) | M5(无) | M6(无) |
| `[20]` | **FN** | **Turbo** | — | **Home** | — | — | — | — |

即：

```
M1    = [19] & 0x04
M2    = [19] & 0x08
FN    = [20] & 0x01
Turbo = [20] & 0x02
Home  = [20] & 0x08
```

按住的键在报文里**持续置位**（不是只发一次脉冲），松开即清；按住 FN 时
`[20]=0x01` 会稳定保持，不会闪断。

**注意**：位图里同时包含标准按钮（A、LB、十字…）的一份副本。这是给
"板载重映射"用的：固件改写的是这份位图，而不是上面的标准按钮字。
详见 [findings-onboard-remap.md](findings-onboard-remap.md)。
